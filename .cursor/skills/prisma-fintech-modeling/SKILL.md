# Skill — prisma-fintech-modeling

## Objectif

Modéliser un domaine financier avec Prisma.

## Processus

1. Identifier agrégats.
2. Identifier invariants.
3. Définir IDs.
4. Définir Decimal.
5. Définir enums.
6. Définir relations.
7. Définir index.
8. Définir audit.
9. Définir soft delete.
10. Préparer migration.

## Interdictions

- Float ;
- suppression de données financières ;
- enum vague ;
- relation sans index ;
- champ JSON pour éviter une vraie modélisation.

## Sortie

- modèle ;
- justification ;
- migration ;
- seed ;
- requêtes types ;
- tests.
